# 🛒 LCAW - Sistema Punto de Venta (Frontend)

Interfaz web interactiva para la gestión de un punto de venta en tiempo real para **Abarrotes Los Chavales WEB**.  
*Proyecto de 5º semestre de bachillerato enfocado en la arquitectura web cliente-servidor y el uso de Inteligencia Artificial como herramienta de desarrollo.*

## 🚀 Tecnologías utilizadas
* **HTML5 / CSS3**: Diseño moderno y responsivo mediante CSS Grid y Flexbox.
* **JavaScript Vanilla (ES6+)**: Organización modular mediante ES6 Modules y consumo de Web Components reusables (`<app-sidebar>`, `<app-header>`).
* **Fetch API**: Comunicación asíncrona en tiempo real con la API del Backend.
* **LocalStorage / SessionStorage**: Gestión de estado local y persitencia de sesión de usuario.

## 📋 Requisitos previos
* Navegador web actualizado (Google Chrome, Brave, Firefox, Microsoft Edge).
* Extensión **Live Server** para Visual Studio Code (o cualquier servidor local de archivos estáticos HTTP).
